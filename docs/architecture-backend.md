# Architecture — Backend (HamzaTex.Api)

**Part:** backend  
**Type:** ASP.NET Core 9 Web API  
**Pattern:** Service-layer API with JWT + ASP.NET Identity

---

## Executive summary

Backend is an ASP.NET Core 9 Web API with Entity Framework Core 9 and MySQL. It uses ASP.NET Identity for users and roles, JWT for authentication, FluentValidation for input validation, and Swagger for API docs. The project is evolving toward a full enterprise system (e.g. email verification, password reset).

## Architecture pattern

- **Layered:** Controllers → Services → Data (DbContext, Entities).
- **Policies:** AdminOnly (RoleId 1), StaffOnly (RoleId 2), AdminOrStaff, Authenticated.
- **Identity:** ApplicationUser, IdentityRole<int>, custom UserRole; RefreshToken stored for JWT refresh.
- **Config:** Connection string and JWT settings from configuration (e.g. appsettings).

---

## Data architecture

- **DbContext:** ApplicationDbContext (Identity + domain DbSets).
- **Entities:** Client, Product, Order, OrderLine, Purchase, Payment, Transaction, Expense, StockMovement, lookups (ClientType, OrderStatus, PaymentType, etc.), RefreshToken, views (VClientBalance, VMonthlyProfitLoss).
- **Migrations:** Under `Migrations/`; DB migrated on startup in development.

---

## API design

- REST under `/api`; controllers: Login, Users, UserRoles, ChangePassword, Client, ClientType.
- Auth: JWT Bearer; Login and Refresh anonymous; others use policies.
- See [api-contracts-backend.md](./api-contracts-backend.md) for endpoints.
- See [data-models-backend.md](./data-models-backend.md) for entities.

## Development workflow

- **Run:** `cd backend/HamzaTex.Api && dotnet run`
- **Swagger:** `http://localhost:5000/swagger`
- **DB:** MySQL; connection string in appsettings. Migrations applied on run.

---

## Security notes

- Password policy: length, digit, upper, lower, non-alphanumeric; lockout after 5 failed attempts.
- **Planned:** Email confirmation (SignIn.RequireConfirmedEmail currently false), password reset, and related enterprise security features.
