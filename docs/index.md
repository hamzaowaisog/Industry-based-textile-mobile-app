## Project overview

HamzaTex is a full-stack application with an ASP.NET Core 9 backend and a React Native (Expo) mobile frontend. The project is evolving toward a full enterprise system (security, email verification) and an offline-first mobile app (Firebase, SQLite). See [project-overview.md](./project-overview.md) for context and direction.

---

## Quick reference

### Backend (backend/HamzaTex.Api)

- **Stack:** .NET 9, EF Core 9, MySQL, JWT, ASP.NET Identity, FluentValidation, Swagger
- **Entry:** `Program.cs`
- **Pattern:** Controllers → Services → Data (DbContext, Entities)
- **API base:** `/api`; Swagger at `/swagger`

### Frontend (frontend)

- **Stack:** React Native, Expo, Redux Toolkit, React Navigation, Axios, AsyncStorage
- **Entry:** `index.js` → `App.js`
- **Pattern:** Screens + Redux + API client (`src/utils/api.js`)
- **Planned:** Offline-first (Firebase, SQLite)

## Getting started

### Backend

```bash
cd backend/HamzaTex.Api
dotnet restore
dotnet run
```

Swagger: `http://localhost:5000/swagger`

### Frontend

```bash
cd frontend
yarn install
yarn start
```

Then press `i` (iOS), `a` (Android), or `w` (web). Set `API_BASE_URL` in `src/utils/api.js` to your backend (e.g. `http://localhost:5000/api`).
