## Critical folders (by part)

### Backend (`backend/HamzaTex.Api`)

| Folder          | Purpose                                                             |
| --------------- | ------------------------------------------------------------------- |
| **Controllers** | HTTP endpoints; auth policies (AdminOnly, StaffOnly, Authenticated) |
| **Entities**    | Domain and EF entities; Identity (ApplicationUser, RefreshToken)    |
| **Services**    | Business logic and orchestration                                    |
| **Data**        | DbContext, MySQL config, seed data                                  |
| **Migrations**  | Schema versioning                                                   |

### Frontend (`frontend`)

| Folder             | Purpose                                        |
| ------------------ | ---------------------------------------------- |

| **src/navigation** | Stack navigator and routes                     |
| **src/utils**      | API client (axios), storage, validation        |

## Entry points

- **Backend:** `backend/HamzaTex.Api/Program.cs` — Kestrel, Swagger, JWT, Identity, CORS.
- **Frontend:** `frontend/index.js` → `App.js` — Expo entry, Redux Provider, Navigation.

---

## Integration

- Frontend calls backend at `API_BASE_URL` (e.g. `http://localhost:5000/api`) via `src/utils/api.js` (axios).
- Auth: JWT; backend uses Bearer token (interceptor in frontend can add `Authorization` when implemented).
- Planned: offline-first (Firebase, SQLite) and enterprise features (e.g. email verification).
