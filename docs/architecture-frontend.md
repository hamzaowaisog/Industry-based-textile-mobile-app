# Architecture — Frontend (HamzaTex Mobile)

**Part:** frontend  
**Type:** React Native (Expo) mobile app  
**Pattern:** Redux + React Navigation; evolving to offline-first

---

## Executive summary

Frontend is a React Native app with Expo, Redux Toolkit for state, and React Navigation (stack). It talks to the backend REST API via Axios. The project direction is **offline-first** using Firebase, SQLite, and related tooling; documentation should support that evolution.

## Architecture pattern

- **Screens:** Home, AddItem, ItemDetails (under `src/screens/`).
- **State:** Redux store with slices (e.g. items); middleware configured (serializableCheck off as needed).
- **Navigation:** Stack navigator; entry via `App.js` and navigation setup in `src/navigation/`.
- **API:** Centralized in `src/utils/api.js` (axios instance, base URL, future auth interceptor).

---

## Data & state

- **Server state:** Fetched via API (items CRUD today; later Login, Clients, etc.).
- **Local state:** React state + Redux; AsyncStorage for persistence today.
- **Planned:** SQLite for local DB, Firebase for sync/auth/features; offline-first design.

## Development workflow

- **Run:** `cd frontend && yarn start` (Expo).
- **Platforms:** `yarn ios`, `yarn android`, `yarn web`.
- **API base URL:** Configured in `src/utils/api.js` (e.g. `http://localhost:5000/api`).

- All server calls go through `src/utils/api.js`.
- Auth: Login/refresh endpoints available; JWT can be added to requests via interceptor when implemented.
