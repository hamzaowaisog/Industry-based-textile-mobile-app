## Authentication & Identity

| Method | Endpoint             | Auth      | Description                                               |
| ------ | -------------------- | --------- | --------------------------------------------------------- |
| POST   | `/api/Login`         | Anonymous | Login with UserName/Password; returns JWT + refresh token |
| POST   | `/api/Login/refresh` | Anonymous | Refresh access token using refresh token                  |
