# Development Guide — HamzaTex

**Project:** HamzaTex  
**Parts:** backend (HamzaTex.Api), frontend (React Native / Expo)

---

## Prerequisites

### Backend

- .NET 9 SDK
- MySQL 8.x (or compatible)
- Connection string in `appsettings.json` / `appsettings.Development.json`

### Frontend

- Node.js 18+
- Yarn or npm
- Expo CLI (optional; `npx expo` works)
- iOS Simulator (Mac) or Android Studio (for emulator)

---

## Backend setup

1. **Navigate to backend:**

   ```bash
   cd backend/HamzaTex.Api
   ```

2. **Restore packages:**

   ```bash
   dotnet restore
   ```

3. **Configure database:**  
   Set `DefaultConnection` in `appsettings.json` or `appsettings.Development.json` for MySQL.

4. **Run API:**

   ```bash
   dotnet run
   ```

   - API: typically `http://localhost:5000` (check launchSettings.json)
   - Swagger: `http://localhost:5000/swagger`

5. **Migrations:**  
   Applied on startup in development. To add new migrations:
   ```bash
   dotnet ef migrations add <MigrationName>
   ```

---

## Frontend setup

1. **Navigate to frontend:**

   ```bash
   cd frontend
   ```

2. **Install dependencies:**

   ```bash
   yarn install
   ```

   or `npm install`.

3. **Configure API base URL:**  
   In `src/utils/api.js`, set `API_BASE_URL` to your backend (e.g. `http://localhost:5000/api`). For physical device, use your machine’s IP instead of `localhost` if needed.

4. **Start dev server:**

   ```bash
   yarn start
   ```

   or `npm start`.

5. **Run on device/simulator:**
   - iOS: press `i` or `yarn ios`
   - Android: press `a` or `yarn android`
   - Web: press `w` or `yarn web`

## Environment / config

### Backend

- Connection string and JWT (Key, Issuer, Audience) in `appsettings*.json`.
- CORS: currently “AllowAll” for development; tighten for production.

### Frontend

- `.env.example` in frontend; copy to `.env` if needed and set `API_BASE_URL` (or keep in `api.js`).

---

## Deployment (high level)

- **Backend:** `dotnet publish -c Release`; deploy to host (e.g. Azure, AWS). Configure production connection string and JWT.
- **Frontend:** Expo build (e.g. `expo build:android` / `expo build:ios`) or EAS Build; follow Expo deployment docs.
