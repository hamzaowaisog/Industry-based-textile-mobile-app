# Project Overview — HamzaTex

**Project:** HamzaTex  
**Type:** Multi-part (backend API + mobile frontend)  
**Direction:** Full enterprise system with security; offline-first mobile app

---

## Executive summary

HamzaTex is a full-stack application with an ASP.NET Core 9 Web API backend (MySQL, JWT, ASP.NET Identity) and a React Native (Expo) mobile frontend with Redux and React Navigation. The project is in early stage and evolving toward:

- **Backend:** Full enterprise features and security (e.g. email verification for reset password and related flows).
- **Frontend:** Offline-first application using Firebase, SQLite, and related tooling.

Documentation is written to support this direction and to give AI-assisted development a clear baseline.

## Tech stack summary

### Backend

- ASP.NET Core 9 Web API, Entity Framework Core 9, MySQL (Pomelo)
- ASP.NET Identity, JWT Bearer, FluentValidation, Swagger
- BCrypt for passwords; policies: AdminOnly, StaffOnly, Authenticated

### Frontend

- React Native 0.81, Expo ~54, Redux Toolkit, React Navigation (stack)
- Axios for API; AsyncStorage for local persistence
- Planned: Firebase, SQLite, offline-first design

---

## Architecture type

- **Backend:** Layered API (Controllers → Services → Data); Identity + JWT.
- **Frontend:** Screen-based app with Redux and stack navigation; API client in `src/utils/api.js`.
- **Integration:** REST; frontend calls backend at configured base URL; JWT for auth (Bearer).
